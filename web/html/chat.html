创建角色

填写角色设定和对话模型；推荐配置记忆模型以检索世界观详细资料，高级选项可按需展开；开场白不填会使用默认值。

支持 PNG / JPG / JPEG / GIF / MP4，单个文件不超过 10MB，画面不超过 2500 万像素。其他情绪未上传时使用这张图；未上传平静图时使用默认背景。

对话模型（LLM） 也就是大语言模型，用来生成角色回复，也就是你和角色聊天时看到的文字；下面的提供商、温度、模型名和 API Key 都属于它。

自定义对话示例

添加用户和角色的对话，让角色参考语气与表达方式。回复不会被固定匹配。

对话模型使用本地 Ollama 前，请先安装并启动 Ollama，并确保已经下载对应模型。否则创建角色后无法正常对话。
选择角色的输出方式

记忆模型（Embedding，可选）

这里的 Embedding 模型不负责生成对话，它只把角色记忆转换成向量，用来辅助 RAG 记忆库检索。不启用时仍沿用原来的总结记忆；启用并配置后，角色更容易记住之前聊过的内容，最直观的效果就是记忆力更好。

记忆模型的配置与回忆效果都不能保证百分之百成功。

为了避免角色成为什么都记得的工具，在回忆以前发生的事情的时候有概率回忆不起来。

开启后，每次回忆有 30% 的概率暂时想不起来，触发后本轮不再尝试回忆。选择会随角色保存。

开启后请选择记忆模型提供商并填写模型名。本地 Ollama 不需要 API Key。

为角色增加更多形象

按情绪上传不同形象，每轮对话会根据角色表现切换。未上传的情绪会显示上方的平静形象。

支持 PNG / JPG / JPEG / GIF / MP4，每个文件不超过 10MB、画面不超过 2500 万像素；虚弱指生病或受伤，疲劳指工作或劳动后的劳累。

要展开思考内容吗？

在相遇之前

为新朋友留一份稳定而长久的记忆。

01记忆模型，请慎重选择
创建后不要修改 Embedding 提供商或模型，更换后可能使已有记忆无法使用。

02让故事安心保存在这里
请不要手动修改角色配置、历史文件或数据库。需要更换记忆模型时，请新建角色；重置记忆库使用当前角色原有的记忆模型。

智能搜索可在创建角色时通过「高级」配置。

重新整理记忆？

将清空当前角色的摘要与原始对话向量，再用已有聊天记录和摘要重新生成。聊天记录与摘要文件会保留；过程可能需要一些时间，并产生记忆模型调用费用。

请保持记忆模型可用；如重建和恢复均失败，记忆库可能不完整，可以根据原始文件重试。
