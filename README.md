# 灵栖 SoulHaven

灵栖是一个运行在自己电脑上的 AI 角色陪伴项目。你可以创建角色、编写世界设定，与角色持续聊天；对话和摘要保存在本地，配置记忆模型后还可以从过去的故事中检索相关内容。

> 项目仍在开发中，后续会持续更新和完善。模型回复和记忆效果取决于所选模型及服务；语音、文件和图片理解等功能尚未完成。

## 能做什么

- **创建角色**：填写角色的人设、关系、说话方式、开场白和形象，选择对话模型。
- **编写世界设定**：使用预置世界或创建自己的世界，并在创建角色时绑定。
- **持续聊天**：查看历史记录、让角色继续说、生成总结；也可以查看角色状态和心声。
- **回忆过去**：可选配置 Embedding 记忆模型，为对话、摘要和详细世界资料建立向量记忆。
- **智能搜索**：创建角色时可在高级选项中配置搜索服务，由模型在需要时使用。

## 简单说说实现思路

灵栖使用网页作为操作界面，Python 后端负责管理角色、聊天和世界设定。对话由你选择的模型服务生成；聊天记录和摘要保存在本地。启用 Embedding 后，项目会将相关内容保存到向量记忆库，供角色在需要时检索。

## 新手快速启动（Windows）

1. 将下载的项目压缩包**完整解压**到一个自己有读写权限的文件夹，然后打开解压后的项目文件夹。不要直接在压缩包内运行。
2. 保持网络连接，双击 **`(小白可选)一键配置环境.bat`**。第一次安装需要下载 Python 或依赖，请耐心等待。看到配置完成提示后，可以关闭这个配置窗口。
3. 双击同一文件夹里的 **`start.bat`**。会出现黑色的终端窗口，请等待程序启动。
4. 启动后通常会自动打开浏览器。如果没有自动打开，请复制下面的地址，粘贴到浏览器的地址栏并按回车：

   **http://127.0.0.1:5000**

5. **使用灵栖期间，请保持 `start.bat` 打开的黑色窗口运行，不要关闭它。** 关闭窗口会停止本地服务，网页将无法继续使用。你可以将窗口最小化。
6. 用完后，回到黑色窗口按 `Ctrl+C` 停止服务，随后按窗口提示关闭。下次使用通常只需要双击 `start.bat`，不必每次重新配置环境。

如果启动窗口提示找不到 Python，或安装过程中遇到错误，请查看下方的「环境准备」和「终端报错排查」。角色开始聊天还需要配置可用的对话模型。

## 环境准备

项目适用于 64 位 Windows，需要 Python 3.12 和可用的对话模型服务。没有配置过 Python 的用户，可以直接按照上面的「新手快速启动」运行一键配置脚本。

使用在线模型时，请准备对应服务的 API Key 和地址；使用本地模型时，请先安装并启动 Ollama，下载要使用的对话模型。Embedding 记忆模型是可选的；需要记忆检索时，也要准备对应的 Embedding 服务或模型。

### 使用已有 Python 手动配置

如果已经装好 64 位 Python 3.12，也可以在项目根目录打开 PowerShell 手动配置：

```powershell
py -3.12 -m venv backend\.venv
if (-not (Test-Path backend\.venv\pip.ini)) {
    "[global]`ncache-dir = $((Get-Location).Path)\backend\.pipcache`nindex-url = https://pypi.tuna.tsinghua.edu.cn/simple`ntimeout = 60" |
        Set-Content -Encoding UTF8 backend\.venv\pip.ini
}
backend\.venv\Scripts\python.exe -m pip install --index-url https://pypi.tuna.tsinghua.edu.cn/simple --cache-dir backend\.pipcache -r backend\requirements.txt
```

如果 `py -3.12` 不可用，但你知道自己安装的 Python 3.12 路径，可以把上面第一行替换为下面的命令，并将路径改成自己电脑上的实际路径：

```powershell
& "C:\Python312\python.exe" -m venv backend\.venv
```

也可以先运行 `python --version` 检查当前命令对应的 Python 版本；确认是 64 位 Python 3.12 后，用 `python -m venv backend\.venv` 创建环境。创建完成后，仍需执行上面创建 `pip.ini` 和安装依赖的命令。已有可用的 `backend\.venv` 时，无需重新创建。

如果安装依赖时 pip 因缓存权限问题卡住，可改用：

```powershell
backend\.venv\Scripts\python.exe -m pip install --index-url https://pypi.tuna.tsinghua.edu.cn/simple --no-cache-dir --disable-pip-version-check -r backend\requirements.txt
```

例如，使用 Ollama 时，先在 Ollama 中准备对话模型；若需要向量记忆，再准备一个 Embedding 模型。模型名称以本地实际安装的名称为准。在线服务则不需要安装 Ollama。

## 启动项目

环境配置完成后，在项目根目录双击 **`start.bat`**，等待服务启动后会自动打开浏览器。也可以在 PowerShell 中运行：

```powershell
backend\.venv\Scripts\python.exe -m backend.app
```

然后访问 [http://127.0.0.1:5000](http://127.0.0.1:5000)。保持启动窗口开启；结束使用时在窗口中按 `Ctrl+C`。当前服务默认只监听本机，不能直接用其他设备访问。

## 第一次使用

1. 打开页面后，先在「世界设定」查看预置世界；如果想使用自己的背景，可以先创建世界观。常驻设定会随对话使用，详细资料依赖角色的记忆模型进行检索。
2. 进入聊天页面，选择「创建角色」，填写名称、人设、开场白及其他希望角色记住的资料，并选择角色所在的世界。
3. 填写**对话模型**提供商和模型名。在线服务按表单填写 API Key、服务地址等；使用 Ollama 时确认服务已启动且模型已下载。
4. 按需启用**记忆模型（Embedding）**并填写它自己的提供商、模型名及连接信息。它负责生成记忆向量，不负责生成聊天回复；不启用也可以聊天，但无法检索详细世界资料。
5. 如需智能搜索，在「高级」中配置搜索服务。保存角色后，选择角色并发送消息开始聊天。

创建后的角色不要随意更换 Embedding 提供商或模型，也不要手动编辑角色配置和数据库；不同模型生成的向量可能不兼容。需要换记忆模型时建议新建角色。

## 使用 AI 智能体协助测试

项目提供 [test 终端接口](test/README.md)，可以让支持执行命令的 AI 智能体根据你的目标检查灵栖。先运行 `start.bat` 并保持黑色窗口开启，再在另一个终端或由智能体运行：

```powershell
.\backend\.venv\Scripts\python.exe .\test\soulhaven.py smoke
```

这个命令会只读检查角色列表、世界列表和默认世界详情，并以 JSON 返回结果。你可以对智能体说：「请先阅读 `test/README.md`，使用 `test/soulhaven.py` 检查灵栖是否正常，报告检查结果。」它也可以按接口支持的范围查询角色、世界、状态和历史，或测试聊天及续说；具体命令见 [test/README.md](test/README.md)。

`chat` 和 `continue` 会调用模型并保存对话，可能产生费用或更改角色数据；需要测试这些功能时，建议使用专门的测试角色。测试能力以接口提供的命令为准。

## 聊天与记忆

聊天记录和总结会保存在本地。聊天界面的「重置记忆库」会根据已有对话记录和摘要重新生成原始对话和摘要的向量，不会删除这些源文件；操作可能需要一些时间，并可能产生模型调用费用。重建前请确保原来的记忆模型可用。

「清空记录」会删除该角色的原始对话、总结及聊天记忆，保留角色开场白；操作不可逆，请先确认是否需要备份。

## 数据与备份

- `characters/`：角色设定、模型配置、角色图片、聊天记录和摘要。
- `lingqi_database/`：每个角色的 Chroma 向量数据库。
- `web/data/`：世界设定数据。

建议在程序停止后一起备份以上目录。角色配置中可能包含 API Key：项目对其使用 Base64 编码，**这不是加密**，请妥善保管备份，不要公开分享。公开仓库不包含本地角色数据、向量数据库和虚拟环境，新下载项目不会包含示例角色或个人数据；四个内置世界观会随项目提供。如将自己的项目上传或分享，请自行排除本地角色、数据库和配置密钥。

## 终端报错排查

遇到错误时，先查看终端中最后一段报错，以及页面上的提示。下面是常见情况的排查方向，并非同一报错的唯一原因。分享日志前，请先遮住 API Key、个人路径、角色资料和聊天内容。

| 终端中可能出现的提示 | 可能原因 | 可以怎么做 |
| --- | --- | --- |
| `No module named ...` 或 `ModuleNotFoundError` | 当前 Python 环境缺少对应依赖，或者启动时使用了其他 Python。 | 在项目根目录重新运行一键配置脚本；手动安装时使用上方的 `backend\.venv\Scripts\python.exe -m pip install ...` 命令，然后用项目虚拟环境启动。 |
| `No suitable Python runtime found`、找不到 `py` 或 Python 3.12 | 未安装合适版本，或 Windows 找不到 Python 启动器。 | 优先运行一键配置脚本；它会尝试准备项目专用的 Python 3.12。安装后重新打开终端再试。 |
| `Address already in use`、`Only one usage of each socket address` 或 `WinError 10048` | 5000 端口可能已被另一个进程占用，也可能已经启动了一个灵栖服务。 | 先检查是否已经有项目启动窗口；关闭不再需要的旧服务后重试。不要随意结束不认识的进程。 |
| `PermissionError`、`Access is denied` 或 `WinError 5` | 项目目录、缓存目录或相关文件没有写入权限，也可能被安全软件拦截。 | 将完整项目解压到自己有写入权限的目录；检查安全软件提示。pip 缓存报错可尝试上方的无缓存安装命令。 |
| `Connection refused`、`Failed to establish a new connection` 或 `WinError 10061` | 目标服务没有运行，或服务地址、端口配置错误；具体目标需看报错中的地址。 | 如果是 `127.0.0.1:11434`，检查 Ollama 是否启动；如果是其他模型服务，检查对应服务地址、端口和网络。 |
| `401` / `Unauthorized` 或 `403` / `Forbidden` | 在线服务可能拒绝了认证或访问权限；不同服务的错误含义会有差异。 | 核对服务商、API Key、地址和账户权限；不要把完整密钥发给他人。 |
| `404` / `model not found` | 模型名或接口地址可能有误，也可能尚未下载本地模型。 | 核对服务商要求的模型名和地址；Ollama 用户确认模型已经下载。 |
| `dimension` / `embedding dimension` 相关错误 | 当前记忆向量维度可能与已有集合不一致，例如更换了 Embedding 模型。 | 确认原记忆模型配置，先备份角色和数据库；不要随意切换模型或直接删除数据库。无法恢复原配置时建议新建角色。 |

终端出现 Flask 的 `WARNING: This is a development server` 是开发服务器提示，不代表启动失败；确认出现监听地址后，再在浏览器打开 `http://127.0.0.1:5000`。

## 常见问题

- **双击启动后提示找不到 Python**：先运行 `(小白可选)一键配置环境.bat`，看到配置完成后再运行 `start.bat`。
- **一键配置下载失败**：确认已联网，并能访问 Python 官网与清华镜像源，再重新运行脚本。Python 安装失败时可查看项目内的 `.runtime/python-install.log`；依赖安装失败时按窗口错误提示排查。
- **网页打不开**：确认启动窗口没有报错、服务仍在运行，并检查本机 5000 端口是否被占用。
- **角色无法回复**：检查所选模型名、服务地址、API Key 和网络；本地 Ollama 用户还需确认 Ollama 正在运行且模型已下载。
- **角色记不住或无法检索详细世界设定**：检查是否为该角色配置了可用的 Embedding 服务。已有记忆出现问题时，可以先备份，再尝试「重置记忆库」。
- **依赖安装卡住**：尝试上面的 `--no-cache-dir --disable-pip-version-check` 命令。
